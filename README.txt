HOW TO PUBLISH (GitHub Pages):
1. Unzip this folder locally.
2. In your GitHub repository, click 'Add file' → 'Upload files' and drag the entire folder contents (index.html, about.html, services.html, contact.html, css/, images/).
3. Commit the changes. In repository Settings → Pages, set the source branch to 'main' and folder to '/ (root)'. Your site will be live at: https://YOUR-USERNAME.github.io/REPO-NAME/

ACTIVATE THE CONTACT FORM (Formspree - free):
1. Go to https://formspree.io/ and sign up for a free account.
2. Create a new form and enter sapna_nandy18@yahoo.co.in as the recipient email when prompted.
3. Formspree will provide a form endpoint URL like: https://formspree.io/f/xyzabcd
4. Open the contact.html file and replace the FORM ACTION value (currently 'https://formspree.io/f/YOUR_FORM_ID') with the URL Formspree gave you.
5. Save and re-upload contact.html to GitHub (or edit in GitHub directly). Test by submitting the form — messages will arrive in the email provided.
